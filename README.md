# Higher-order-interactions

## DESCRIPTION

This is a Julia program designed for calculating the benefit-to-cost ratio of any higher-order networks. 

## Get started

Julia 1.7 and following packages is required:

- Finch
- Combinatorics
- Symbolics

If run this project in Syslab, Symbolics package is provided by Syslab environment thus not needed to be installed
